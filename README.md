## 项目简介

低轨（LEO）卫星网络具有**高动态、链路间歇通断、几何参数快变**等特性，传统静止轨道通信假设不再适用。本仓库提供一条从 STK 仿真原始导出到标准化训练数据集的预处理流水线：

1. 在 STK 中基于真实在轨卫星 TLE 两行轨道根数，借助 **SGP4 摄动模型** 完成 LEO 轨道推演；
2. 配置地面站最低仰角约束与 LOS 视线判据，执行星地链路 Access 访问仿真；
3. 导出 **AER（方位角 / 仰角 / 斜距）几何时序数据** 与 **Access 过境时隙表**；
4. 使用 Python 完成原始数据清洗、UTC 时间校准、过境窗口关联；
5. 基于自由空间路径损耗（FSPL）模型离线计算信道增益与电波传播时延；
6. 自动统计每次过境链路指标，输出标准化数据集并绘制时序可视化曲线。

输出数据集可直接喂入低轨卫星链路调度、切换、资源分配等算法的研究与训练流程。

## 仿真场景

| 项目 | 配置 |
| :--- | :--- |
| 卫星 | CBERS-2B 遥感卫星 |
| 轨道数据源 | NORAD TLE 两行轨道根数 |
| 轨道传播模型 | SGP4 简化广义摄动模型（STK 内置） |
| 地面站 | 长春地面站（Changchun） |
| 通信可见约束 | 最低仰角 5°、LOS 视线判定 |
| 仿真时长 | 24 h，采样步长 60 s |
| 仿真日期 | 2026-09-15（UTC） |

**STK 原始输出**

- `access链路时隙表.csv`：每次卫星过境的起止时间、持续时长
- `aer几何时序数据.csv`：方位角 Azimuth、仰角 Elevation、星地斜距 Range 时序采样

## 核心功能

1. **STK 原始数据解析**
   - 读取 STK 导出的 CSV，自动清洗表头多余空格
   - UTCG 时间字符串解析为带时区的 UTC datetime
   - 时间戳去重、缺失剔除、时序排序
2. **过境时隙标准化处理**
   - 按 Access 起止时间切片 AER 时序数据
   - 为每条 AER 采样点绑定所属过境编号 `access_id`
   - 输出结构化链路过境汇总表（时长、采样点数、几何极值）
3. **通信信道参数离线建模**
   - 自由空间路径损耗 FSPL 计算
   - 信道增益（路径增益，负 dB）求解
   - 电波传播时延 τ = d / c，自动单位换算
4. **链路指标批量统计**
   - 按单次过境分组统计：斜距、仰角、路径损耗、信道增益、传播时延的最大 / 最小 / 平均值
5. **多维时序可视化**
   - 四联时序图：仰角、星地斜距、FSPL、传播时延
   - 按 Access 分色，虚线标记过境起止窗口

## 方法原理

### 自由空间路径损耗 (FSPL)

$$
\mathrm{FSPL}(d) = 20 \log_{10}\!\left(\frac{4\pi d}{\lambda}\right) \quad [\mathrm{dB}]
$$

其中 $d$ 为星地斜距（m），$\lambda = c / f$ 为载波波长（m）。

### 信道增益

$$
G_{\text{channel}}(d) = -\mathrm{FSPL}(d) \quad [\mathrm{dB}]
$$

仅含自由空间传播损耗，不含收发天线增益、大气损耗等其他项，便于后续算法层叠加。

### 电波传播时延

$$
\tau(d) = \frac{d}{c} \quad [\mathrm{s}], \quad c = 2.99792458 \times 10^{8}\ \mathrm{m/s}
$$

## 快速运行

1. 将 STK 导出的两份 CSV 放置于项目根目录（默认文件名见 [文件目录](#文件目录)）。
2. 执行流水线脚本：

   ```bash
   python stk_link_pipeline.py
   ```

3. 运行结束后，根目录自动生成：
   - `标准化链路过境时隙表.csv`
   - `链路参数时序数据.csv`
   - `链路时序曲线.png`

控制台会同步打印每次过境的统计摘要，便于快速核对。

## 输出说明

### `标准化链路过境时隙表.csv`

每次过境一条记录，字段：

| 字段 | 含义 |
| :--- | :--- |
| `access_id` | 过境编号 |
| `start_utc` / `stop_utc` | 起止 UTC 时间 |
| `duration_s` | 过境持续时长 (s) |
| `sample_points` | AER 采样点数 |
| `az_min/az_max_deg` | 方位角极值 (°) |
| `el_min/el_max_deg` | 仰角极值 (°) |
| `range_min/range_max_km` | 斜距极值 (km) |

### `链路参数时序数据.csv`

每条 AER 采样点一行，字段：

| 字段 | 含义 |
| :--- | :--- |
| `time_utc` | UTC 时间戳 |
| `access_id` | 所属过境编号（-1 表示未被任何 Access 覆盖） |
| `azimuth_deg` | 方位角 (°) |
| `elevation_deg` | 仰角 (°) |
| `range_km` / `range_m` | 星地斜距 |
| `fspl_db` | 自由空间路径损耗 (dB) |
| `channel_gain_db` | 信道增益 (dB) |
| `prop_delay_ms` | 电波传播时延 (ms) |

### `链路时序曲线.png`

四联子图，自上而下依次为：仰角、星地斜距、自由空间路径损耗、传播时延；不同过境以颜色区分，灰色虚线标注每次 Access 的起止时刻。

## 可配置参数

主流水线脚本顶部可调参数：

```python
FREQ_HZ = 20e9   # 载波频率 (Hz)，默认 20 GHz Ka 波段，可改 S/X/Ku 等波段
```

如需修改地面站约束、卫星、采样步长等场景参数，请在 STK 仿真端修改后重新导出 CSV。

## 注意事项

- 时间解析针对 STK 默认 UTCG 格式（如 `15 Sep 2026 05:50:18.127`）；若导出格式不同，请相应修改 `STK_TIME_FMT`。
- FSPL 模型仅含自由空间损耗，未包含大气、雨衰、极化失配等损耗项，可按需在输出 CSV 上叠加。
- 信道增益定义为 `-FSPL`，不含收发天线增益；端到端链路预算需另行加入天线增益与系统噪声。
- 默认载波频率 20 GHz，Ka 波段；NTN 实际下行频段（如 S 波段 2.2 GHz）FSPL 数值会显著不同。
