# leo-stk-link-dataset-preprocessing
> 仓库简介：低轨星地链路端到端数据流水线，解析 STK 导出 AER 与时隙数据，计算自由空间损耗，生成 NTN 标准化链路数据集并完成时序指标可视化。

## 📌 项目简介
面向 **NTN（非地面网络）低轨卫星通信** 高动态、链路间歇通断特性，搭建**STK仿真 + Python后处理**端到端数据预处理流水线。

在STK中基于真实在轨卫星TLE两行轨道根数，借助SGP4摄动模型完成LEO卫星轨道推演，配置地面站仰角约束与视线可见判据，执行星地链路Access访问仿真；导出AER几何时序数据与链路过境时隙表。
使用Python完成原始仿真数据清洗、UTC时间校准、过境窗口关联；基于自由空间路径损耗模型离线计算信道增益与传播时延，自动统计每次过境链路指标，输出标准化数据集并绘制时序可视化曲线。
整套方案实现**轨道仿真与通信算法训练解耦**，输出数据集可直接用于低轨卫星链路调度、资源分配算法研究。

## 🛰️ 仿真场景
- 卫星：CBERS‑2B 遥感卫星
- 轨道数据源：NORAD TLE两行轨道根数
- 轨道传播模型：SGP4简化广义摄动模型（STK内置）
- 地面站：长春地面站
- 通信可见约束：最低仰角 5°、LOS视线判定
- 仿真时长：24h，采样步长60s
- STK原始输出：
  - Access时隙汇总表：记录每次卫星过境起止时间、持续时长
  - AER时序数据：方位角Azimuth、仰角Elevation、星地斜距Range

## ✨ 核心功能
1. **STK仿真原始数据解析**
    - 读取STK导出CSV，自动清洗表头多余空格
    - UTCG时间格式解析、时间戳校准、去重与时序排序
2. **过境时隙标准化处理**
    - 识别每一段卫星Access过境窗口
    - 将AER时序采样点与对应过境编号绑定
    - 输出结构化链路过境汇总表
3. **通信信道参数离线建模**
    - FSPL自由空间路径损耗计算
    - 信道增益、电波传播时延求解，自动单位换算
4. **链路指标批量统计**
    按单次过境分组统计：斜距、仰角、路径损耗、信道增益、传播时延的最大/最小/平均值
5. **多维度时序可视化**
    自动生成四联时序图：仰角、星地斜距、自由空间损耗、传播时延，用虚线标记过境起止窗口
